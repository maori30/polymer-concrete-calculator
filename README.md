# מחשבון בטון פולימרי — Apple Glass Edition (מנוע גרייש) ⚖️✨

מחשבון אינטראקטיבי מתקדם ומדויק לחישוב כמויות שקילה של אבקה ונוזל/מים ליציקות בטון פולימרי, רזין אקרילי וגבס פולימרי, מותאם ב-100% לאלגוריתם ולחומרים הרשמיים של **GRAYISH (גרייש)**.

מעוצב בסגנון **Apple Glass (visionOS / macOS)** יוקרתי, בהיר, קריסטלי ונגיש במיוחד עם התאמה מושלמת למסכי מובייל ו-iPhone Pro Max.

## 🚀 תכונות מרכזיות
- **מנוע החישוב הרשמי של גרייש:** מבוסס על שקילת מים בתבנית ומקדמי המיצוק המדויקים ($x$ ו-$y$).
- **כל 9 החומרים של גרייש:**
  - שלג פולימרי פרו (Snow Pro) — יחס 3:1
  - שלג 100% לבן (Pure White) — יחס 3.2:1
  - GYSMO PRO — יחס 3.3:1
  - GYSMO FLEX — יחס 3.5:1 (גמיש ועמיד לשבירה)
  - סהרה פולימרית — יחס 3.5:1
  - אבן ירושלמית — יחס 3.8:1
  - מיראז׳ אבן אפריקאית — יחס 3.5:1
  - שלג אבקת קמין — עמיד בחום
  - NIKA A1 — מערכת דו-רכיבית
- **חישוב לפי שקילת מים או מידות גיאומטריות (ס"מ):** מלבן, גליל ומגש אובלי.
- **המלצת אריזות לרכישה:** כולל מחירי האריזות המשתלמות ביותר ישירות מאתר גרייש.
- **4 כללי הברזל למניעת שבירה:** טיפים מעשיים לזמני שליפה, איסור הוספת מים וייבוש סופי.
- **Apple Glass Design:** זכוכית חלבית בהירה, כפתורי פסיעה נוחים, כרטיסי שקילה ברורים ומצב כהה/בהיר.
- **פעולות מהירות:** העתקת מתכון מוכן ללוח, שמירת מתכונים מקומית והדפסה מותאמת לסדנה.

## 🛠️ טכנולוגיות
- HTML5 / CSS3 / Vanilla JavaScript
- Tailwind CSS (via CDN)
- Lucide Icons
- Apple Glassmorphism (Backdrop filters & specular reflections)
